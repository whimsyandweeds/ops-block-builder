# Ops Block Builder

A modular business operating system stack builder. This is a self-contained React artifact (single HTML file) for selecting and estimating business service "blocks" such as Bookkeeping, Collections, Fractional CFO, Custom Apps, and more.

## Live Preview

Open `index.html` in a browser, or view it on GitHub Pages if enabled.

## Features

- Select Core and Advanced service blocks
- Real-time monthly and one-time cost estimates
- Tactile visual stack builder
- Diagnostic / evaluation request form

Created from the attached React artifact.
